# Web Dev Club Website

A responsive 7-page static HTML/CSS/JS implementation based on the supplied Website Plan.

## Pages
1. `index.html` — Home
2. `about.html` — About
3. `events.html` — Events
4. `projects.html` — Projects
5. `resources.html` — Resources
6. `join.html` — Join / Get Involved
7. `blog.html` — Blog / Updates

## Shared files
- `styles.css` — shared responsive styling
- `main.js` — navigation, demo data, filtering and demo form behavior
- `assets/` — place real images/icons here

## Run locally
Open `index.html` in a browser. No framework, package manager or build step is required.

## Before launch
Replace all placeholder data marked `TBD`, `20XX`, `XX`, `club@example.edu`, names, meeting details, social links and demo form behavior. Connect real RSVP/signup/calendar/community links.

The source plan also calls for a decision on whether Events/Projects should be hand-edited in HTML or maintained from a simple JSON data source, and whether projects should have dedicated detail pages.
