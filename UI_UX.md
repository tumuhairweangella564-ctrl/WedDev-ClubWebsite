# UI/UX Direction

## Design concept
A modern student-tech identity: dark interface, high-contrast typography, purple/teal accent treatment, rounded cards and subtle depth. The site should feel credible to faculty/recruiters while remaining welcoming to beginners.

## Information hierarchy
1. Immediate identity + purpose
2. Primary action: Join
3. Current activity: Events
4. Proof: Projects
5. Value: Resources
6. Credibility: About / leadership
7. Ongoing activity: Blog

## Component system
- Sticky navbar
- Highlighted Join Us CTA
- Hero sections
- Stats bar
- Cards
- Filter pills
- CTA bands
- Timeline
- FAQ accordions
- Shared footer
- Responsive mobile navigation

## Interaction principles
- Keep Join Us visible.
- Use active navigation state.
- Filters should update content without a page reload.
- Use clear status labels for projects.
- Keep recurring meeting information separate from one-off events.
- Cross-link Events ↔ Resources and Projects ↔ Join.
- Avoid animation that harms readability or accessibility.

## Responsive behavior
- Desktop: multi-column grids.
- Tablet: collapse navigation and reduce grid columns.
- Mobile: single-column content, full-width CTAs, stacked stats.

## Accessibility
- Semantic headings.
- Keyboard-focusable controls.
- Visible focus states.
- Descriptive link labels.
- Alt text for real images.
- Sufficient contrast.
- Do not rely on color alone for status/category.
