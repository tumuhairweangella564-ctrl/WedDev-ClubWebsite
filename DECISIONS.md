# Decisions Required Before Launch

These are unresolved in the supplied Website Plan or explicitly marked optional/decision-needed.

1. **Official identity**
   - Club name, logo, colors, tagline and approved mission.

2. **Membership**
   - Who can join?
   - Any prerequisites?
   - Free or dues?
   - Expected attendance/project/Discord participation?

3. **Operations**
   - Meeting day/time/frequency/location.
   - Official contact email.
   - Faculty advisor, if applicable.

4. **Data maintenance**
   - Hand-edit Events and Projects in HTML, or store data in JSON?
   - Recommended for this static MVP: JSON if officers need easier updates.

5. **Project detail pages**
   - Card-only MVP, or one detail page per project?
   - Recommended: card-only for MVP; add detail pages for standout projects.

6. **Resources access**
   - Fully public or members-only?
   - If members-only is required, a plain static site cannot provide secure authentication by itself.

7. **Blog publishing**
   - Hand-authored HTML pages or a content workflow/CMS?
   - For a strict no-build static site, individual HTML posts are simplest.

8. **Integrations**
   - Discord invite.
   - Google Form/Typeform.
   - Google Calendar/iCal.
   - Newsletter provider.

9. **Optional features**
   - Sponsors/partners.
   - Photo gallery.
   - Event suggestion form.
   - Resource contribution form.
   - Newsletter.
   - Search/archive pagination.
   - Open-source contribution strip.
   - Career prep section.

10. **Launch scope**
   - Mark each optional feature as MVP, Phase 2 or not planned.
